# SUNBIT - 統合ワークスペースポータル

## 概要

このプロジェクトは、Google Apps Script を利用して構築された統合ワークスペースポータルです。Gmail、Google ToDo、Googleカレンダー、Google Chat の情報を一元的に表示し、カスタムリンク管理機能を提供します。ユーザーは自分専用のポータルを通じて、日々の業務に必要な情報に素早くアクセスできます。

## 機能

### 1. ユーザー情報表示
* ログインユーザーのメールアドレスと名前を表示します。

### 2. Gmail連携
* 未読メールのスレッド数と最新の未読メールを最大100件表示します。
* 特定のメールスレッドを既読にしたり、スレッド内の全メッセージと添付ファイルを閲覧できます。
* メールに添付されたファイルをダウンロードできます。

### 3. Google ToDo連携
* Google ToDoリストのタスク（サブタスク含む）を表示し、期日順にソートします。
* 新しいタスクやサブタスクの追加、既存タスクの更新、完了、削除が可能です。

### 4. Googleカレンダー連携
* 特定の日のカレンダーイベントを表示し、Google ToDoの期日付きタスクも合わせて表示します。
* イベントの追加、更新、削除が可能です。
* 特定の月のイベントがある日付を表示します。

### 5. Google Chat連携
* 未読のGoogle Chatスペース数を表示します。

### 6. カスタムリンク管理
* よく使うウェブサイトへのカスタムリンクを登録・管理できます。
* リンクにはタイトル、URL、アイコンを設定でき、自動的にファビコンも取得します。
* リンクをフォルダで整理し、フォルダの作成、更新、削除が可能です。
* リンクとフォルダの順序を自由に並べ替えたり、フォルダ間での移動も行えます。

## セットアップ方法

1.  **Google Apps Script プロジェクトの作成:**
    *   Google Driveで新しいGoogle Apps Scriptプロジェクトを作成します。
    *   `appsscript.json`、`コード.js`、`Index.html` の内容を、それぞれ新しいスクリプトプロジェクトの対応するファイルにコピー＆ペーストします。

2.  **必要なサービスの有効化:**
    *   Apps Scriptエディタの左側のメニューから「サービス」アイコン（`+`記号）をクリックします。
    *   以下のサービスを検索して追加します。
        *   `Gmail API`
        *   `Tasks API`
        *   `Calendar API`
        *   `Chat API`

3.  **ウェブアプリとしてのデプロイ:**
    *   Apps Scriptエディタの右上にある「デプロイ」-> 「新しいデプロイ」をクリックします。
    *   デプロイタイプの選択で「ウェブアプリ」を選択します。
    *   「実行者」を「自分」に設定し、「アクセスできるユーザー」を「全員」（または必要に応じて組織内のユーザー）に設定します。
    *   「デプロイ」をクリックし、初回実行時には認証を求められるため、指示に従って必要な権限を許可してください。
    *   デプロイが完了すると、ウェブアプリのURLが発行されます。このURLにアクセスすることでポータルを利用できます。

## 使い方

デプロイされたウェブアプリのURLにアクセスすると、統合ワークスペースポータルが表示されます。各種機能は、UIを通じて直感的に操作できます。

## 必要な権限

このスクリプトは以下のGoogleサービスへのアクセス権限を必要とします。

*   Googleアカウント情報 (`Session.getActiveUser()`, `PropertiesService`)
*   Gmail (`GmailApp`)
*   Google ToDo (`Tasks.Tasklists`, `Tasks.Tasks`)
*   Googleカレンダー (`CalendarApp`)
*   Google Chat (`Chat.Spaces`)

これらの権限は、初回デプロイ時または初回実行時にGoogleによって承認を求められます。
